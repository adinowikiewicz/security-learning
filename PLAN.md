# Cybersecurity Learning Plan

## Phase 1: Foundation (0-3 months)
- Linux basics
- Networking fundamentals
- Git & GitHub
- Basics scripting (Bash, Python)

## Phase 2: Security Fundamentals (3-6 months)
- System hardening
- Vulnerability basics
- Web security

## Phase 3: Practical Skills (6-9 months)
- TryHackMe / HackTheBox labs
- Small security projects
- Log analysis
- Basic incident response

## Phase 4: Job Read (9-12 months)
- Portfolio polishing
- CV + LinkedIn
- Interview preperation
- Junior jo applications
